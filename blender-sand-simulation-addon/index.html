    Welcome to HiPhyEngine!#

    The most powerful physics simulation addon for Blender to give you the tools to create studio quality physics simulation results! Developed by a former simulation software developer from Walt Disney Animation Studio, HiPhyEngine is fast, intersection-free, all-in-one multi-physics simulation engine designed for full artistic control without compromising performance. It has many exclusive features that are not available in any other commercial physics simulators.

    Key Features
    HiPhyEngine is a fully-coupled high fidelity physics engine. It is capable of simulating rigid body, hair, cloth, soft body in a unified solver while guarantees intersection free! No other commercial physics simulation engines, in Blender or other packages, have the capability for fully-coupled physics simulation, or guarantees intersection free physics simulation.
    HiPhyEngine also comes with a MPM solver that brings snow and sand simulation to blender, which are only previous available in other subscription based softwares!

    You can try HiPhyEngine for 6 months! You will have the chance to fully experience the engine before making a purchase!

    Once purchased, you can keep use the current version forever and gain access to one year of feature updates. Many of the most expensive commercial subscription-based production software does not have many of the features that HiPhyEngine provides!

    Comparison To Blender's Internal Physics Simulation

    Blender uses position-based dynamics with a mass-spring system with discrete collision detection, it is fast, however is less accurate. HiPhyEngine uses finite element discretization with continuous collision detection. HiPhyEngine's simulation result is more physically accurate, and guarantees intersection free, even with complex and multi-layered collisions, and no matter how fast an object is moving, or how thin it is.

    HiPhyEngine's finite element discretization has the benefit of resolution independence. Using lower resolution simulation for iterative parameter tuning in HiPhyEngine will guarantee the same large scale behaviors when increase the simulation resolution.

    Full Artistic Control

    HiPhyEngine gives user full artistic controls. Most simulation parameters can be animated and mapped. In Blender, user can utilize attributes and geometric nodes to create animated simulation parameter maps for HiPhyEngine. HiPhyEngine also provides integration with the expression language SeExpr2 to give user more ways to create force fields and attributes.

    Your All in One Solver

    HiPhyEngine is a fully coupled physics simulation engine for five different material models. Need to couple cloth and rigid body? Cloth and hairs? Soft bodies? No need for the extra set up! HiPhyEngine will take care of all the interactions!

    Robust and Clean Simulation Result

    HiPhyEngine guarantees intersection free simulation result. No matter how fast things are moving, how thin, if there is a intersection-free solution, HiPhyEngine will find it! To give user maximum control, user can use animated maps to activate/deactive collision on demand anywhere, at any frame.

    Special Features

    Gravity is pulling your carefully groomed hairs down? No worries! HiPhyEngine has an inverse simulation technique that automatically generates the rest shape that compensates for gravity and other external forces. Animators are handing you meshes that go through themselves? HiPhyEngine's soft collider feature will automatically clean up incoming animation mesh makes them intersection free and ready for physics simulation. HiPhyEngine also has solver space, unit conversion, time scale, and tons of other features to explore!

    Snow, Sand, and Beyond

    HiPhyEngine also provides a MPM solver, that is capable to simulate variety of phenomenons with fluid/solid mixture, such snow, sand, mud, or even bread dough!

    How HiPhyEngine Is Developed

    We architected HiPhyEngine from ground up, all material models, collision alorithms are developped without AI generated code to ensure the HiPhyEngine is maintainable and easily extendable. We derived and verified all the mathematical formulations by hand, and unit tested everything to ensure correctness. This is why we can gurantee intersection free simulation, and robust simulation results.
